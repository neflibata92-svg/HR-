# LEION HR 原版设计还原与真实功能融合规格

## 1. 目标

将 `beyondx-style-dashboard.html` 中已确认的 LEION HR 原版视觉、页面结构和交互完整迁回正式 Vue 前端，同时保留当前已经接入的真实认证、岗位、候选人、简历上传、Agent 状态、Agent Key 与 HR 账号管理功能。

本次还原的核心原则是：**原版设计负责界面结构与视觉表达，真实 API 负责业务数据与操作结果。** 不再因为后端暂缺某项接口而删除对应版块，也不使用原型演示数字冒充真实数据。

`/Users/yueguanshengren/Desktop/Resume_Screening/.superpowers/brainstorm/47853-1789903760/content/beyondx-style-dashboard.html`

需要恢复的核心视觉语言：

- 深靛蓝 `#090E80` 主色，辅以紫色 `#7C65EB` 与青色 `#83E4EC` 渐变。
- 白色、淡蓝紫半透明玻璃面板，以及柔和阴影和背景光晕。
- 32px 外壳圆角、20–30px 内容卡片圆角、胶囊按钮和导航。

## 3. 数据展示原则

每个原版模块都必须保留其位置和版式，并按以下优先级展示内容：

1. **真实接口可提供**：展示真实数据和真实操作。
2. **正在请求**：在原版卡片内部显示加载状态或骨架内容，不让页面结构塌陷。
3. **请求失败**：在原版卡片内部显示错误原因和重试按钮，不伪装成正常空数据。
4. **真实结果为空**：保留原版模块，显示与原版风格一致的空状态。
5. **后端没有接口**：保留原版标题、卡片和说明区域，明确标注“暂未接入”，不显示原型数字、候选人或运行状态。

禁止把原型中的 `326`、`148`、`126`、`37`、示例候选人、示例岗位或示例设备当作正式数据。原型内容只用于决定模块结构、文字层级和视觉样式。

## 6. 工作台

- 当前没有任务控制接口，因此卡片显示“任务控制暂未接入”。
- 岗位名称可使用真实岗位列表中的启用岗位；没有岗位时显示“暂无运行岗位”。
- 暂停和停止按钮在接口缺失时保持禁用，并说明原因，绝不做假操作。

- 评分达标

### 6.3 实时任务流

- 保留原版事件列表面板和行结构。
- 有真实活动接口时再接入；当前显示原版风格的“实时动态暂未接入”空状态。

### 6.4 共享额度

- 保留 `200 次 / 天`、进度条、剩余量、全岗位共享说明及岗位消耗列表的版式。

### 6.5 Agent 状态

- 将当前真实 Agent 设备列表融入工作台下方的原版面板，不删除该真实功能。
- 展示机器 ID、状态、最近心跳和最近错误，并保留失败重试。

## 7. 岗位管理

- 岗位卡片展示真实名称、状态、JD 摘要、评分阈值。
- 候选人数和最近运行时间只有接口返回时才展示，否则显示 `—`。

- 详情抽屉恢复 JD、硬性条件、AI 阈值、问候语和任务状态分区。

- 岗位页面不得出现独立招呼额度配置。
- 加载、失败、空列表和保存失败均在原版布局内展示，不清空用户正在填写的表单。

## 8. 候选人

- 姓名、基础资料、来源及已有真实字段正常显示。
- AI 分数、判断摘要、问候状态、简历状态缺失时显示 `—` 或“暂未接入”。
- 四项统计仅从真实返回数据中能够可靠计算的部分计算；不能可靠计算的显示 `—`。
- 详情抽屉恢复经历摘要、匹配证据、风险提示和活动时间线分区；缺少接口的分区分别显示能力边界，而不是删除整个抽屉。
- “标记简历交换”继续调用真实 API，并保留失败反馈和列表状态。
- “查看简历”等后端不支持的操作保持禁用并说明原因。
