多电脑调度模型

调度单位是“电脑 / Agent”，每台电脑独占一个运行任务；不同电脑互不阻塞。

任务分配规则

① 用户选择“电脑 + 岗位”创建任务
② 服务端检查该电脑是否在线、是否空闲、BOSS 是否已登录
③ 创建机器独占锁，保证同一电脑只领取一个任务
④ Agent 领取任务并持续上报心跳、进度和运行日志
⑤ 完成、停止或心跳超时后释放锁；异常任务标记为中断，不自动重复发送

支持的情况

  • 电脑 A 跑岗位 1，电脑 B 同时跑岗位 2
  • 同一岗位可分给不同电脑，但各自按候选人去重
  • 电脑离线后保留进度，恢复时由用户决定是否继续
  • 每台电脑独立统计发送限额和登录状态

禁止或保护

  • 同一电脑同时启动第二个岗位
  • 离线电脑接收新任务
  • Agent 心跳中断后继续计算为“运行中”
  • 失败重试时再次问候同一候选人

任务状态

待领取 → 运行中 ⇄ 已暂停 → 已完成　｜　运行中 → 异常中断 / 已停止

下一项需要确认：同一个 BOSS 账号是否可能同时登录在多台电脑运行？推荐首版禁止，按“BOSS 账号 + 电脑”双重防冲突。
