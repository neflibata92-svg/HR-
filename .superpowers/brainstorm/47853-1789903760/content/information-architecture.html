四个模块的职责

1

工作台

选择一个岗位启动任务；展示 Agent/BOSS 登录状态、实时进度、漏斗、错误和停止控制。首版同一时间只运行一个岗位，避免多岗位切换导致误发。

2

岗位

管理 JD、问候语、硬筛条件、评分维度与权重、达标阈值、发送上限。AI 从 JD 生成草案，必须人工确认后才能启用。

3

候选人

默认按岗位查看漏斗阶段：新发现、已筛选、已问候、已回复、已收简历、淘汰；支持查看评分明细、筛选原因和沟通记录。

4

简历库

统一保存 BOSS 自动收到的附件和手工上传的已有简历；支持岗位标签、来源、解析状态、去重、搜索及关联候选人。

核心数据流

创建岗位/JD → AI 生成评分标准 → 人工确认启用
工作台选择岗位 → 下发任务 → 本机 Agent 浏览 BOSS 推荐页
发现候选人 → 硬筛 → 模型评分 → 达标后发送问候 → 回传结果
候选人回复附件 → Agent 下载 → 简历解析/去重 → 简历库归档 → 关联岗位与候选人

需要确认的产品边界：首版是否接受“同一时间只运行一个岗位”？这是最安全、最快形成闭环的方案。
